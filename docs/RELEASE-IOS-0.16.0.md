# MotoNav iOS 0.16.0 · 导航语音走圆屏扬声器

在 0.15.0 基础上，把安卓 8.3.26-single.30「圆屏发声」能力对齐到 iOS：导航播报改从圆屏喇叭出声，手机端不再念，并可在 App 里直接调圆屏音量。由 AI 开发，源码已同步至 GitHub。

## 本轮新增

| 功能 | iOS 0.16.0 的实现 |
| --- | --- |
| 从圆屏扬声器播报 | 「导航语音」设置里新增开关。打开后，导航播报用系统语音合成成 16kHz 单声道 PCM，经新增的 BLE 特征值 `6e400004-...`（AUD）流推给圆屏：先发 `#AUD,1` 开始，按 320 字节 / 10ms 实时推流，播完发 `#AUD,0` 结束；手机端不激活音频会话、不出声 |
| 圆屏扬声器音量 | 设置里 0~100 滑杆，拖动即发 `#VOL,N`；固件用 ES8311 的音量接口生效并存 NVS，圆屏重启后音量不丢；连上圆屏时自动补发一次 |
| 打断与静音 | 新播报打断上一句（旧句合成回调作废）；点「导航静音」、关掉开关或断开圆屏立即发 `#AUD,0` 掐断。语速、音调、音色选择对圆屏发声同样生效（都作用在合成上） |
| 旧系统兜底 | iOS 17 以下没有 PCM 合成接口，自动退回手机出声，功能不受影响 |

**圆屏发声需要圆屏固件 v7.12.17-pages.5 及以上**（本轮同步交付）。旧固件没有 AUD 特征值和 `#VOL` 命令：开关照常显示，但播报会保持静音，升级固件后即生效。

## 继续保留的已有功能

- 0.15.0 全部功能：摩托车原生规划、自行车规划、网页电子眼、蓝牙恢复、中文播报音质等（见 0.15.0 发布说明）。
- 手机端出声链路原样保留：不开「从圆屏扬声器播报」时，行为和 0.15.0 完全一致。

## 安装与验证

- IPA 为免签名包，用 TrollStore 安装（步骤见 INSTALL-IOS.md）；也可用个人签名工具自签。
- Bundle ID 仍为 `org.esp32nav.motonav`（高德 Key 绑定此 ID），升级安装无需重新填 Key。
- 建议按顺序验收：① 圆屏烧好 v7.12.17-pages.5 固件 → ② App 里打开「从圆屏扬声器播报」→ ③ 拖「圆屏音量」滑杆，点「试听播报」→ 圆屏喇叭应立即出声且手机不响。

## 验证边界

- 本轮未做 Xcode 类型检查 / 链接，也未在 iPhone 上实测；CI（macOS runner + CocoaPods 1.16.2）编译通过并出包，不代表所有机型行为已验证。
- PCM 流走 BLE 无响应写（320 字节 / 10ms，约 32KB/s）；长隧道等信号极差环境可能断续，固件断流 900ms 自动结束本次播报。
- 圆屏发声时「播报时压低音乐」对手机无效（手机本来不响），对圆屏行为无影响；该开关保留给手机出声模式。

使用时请遵守交通法规，骑行中勿操作手机。使用本套程序视为自愿承担可能带来的交通事故风险。
